# The template is English only

`harness validate` reports a Georgian letter in a file git tracks or is about to track; a project whose product text is
Georgian narrows it with `english_only:`; a summary is English, one page, `<name>.summary.md`; the attack stage writes
`output/summary.md`; the Georgian design record is in the owner's vault.
