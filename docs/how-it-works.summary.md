# How it works, step by step: summary for the owner

- One run of the pipeline skill start to end: a sequence diagram and a table of twelve steps, each with who acts, the
  record it writes and what closes it.
- Then nine steps in detail, each with the file it writes: the run folder, the briefs and the facts pack, the launch
  table (its estimate from the last measured run) and the one yes, the sessions and the watcher (when it returns to
  the manager, and why; the spec-writer first when no spec exists), plan and critique, build, verify, hand-over and a
  repeat's unit size, the sandbox (in detail on its own page) and the end of a run (on its own page too: the judge,
  the merge and the push, the score and the measurement page, the decisions into the vault, the collector).
- A link to the table of the run's files (its own page): who writes each and what a human reads there.
