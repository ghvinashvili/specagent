## Decisions (global)

- [a-rule-broken-twice-becomes-code](decisions/global/a-rule-broken-twice-becomes-code.md): A rule broken a second time becomes a check in code
- [agent-orders-give-the-reason-without-shouting](decisions/global/agent-orders-give-the-reason-without-shouting.md): Every agent order says why, in calm wording without capitalised alarm words
- [agents-are-blind](decisions/global/agents-are-blind.md): Every launched agent is blind - fresh context, material and question only, never my conclusions or the owner's authority
- [agents-work-in-english](decisions/global/agents-work-in-english.md): Pipeline agents work in English from the first word
- [answers-short-plain-bottom-line-first](decisions/global/answers-short-plain-bottom-line-first.md): Answers are short, in plain words, bottom line first; the domain fact behind a decision is explained
- [cache-and-compaction](decisions/global/cache-and-compaction.md): A role's session compacts instead of handing over and reads its frozen lane pack from the prompt cache
- [chats-get-every-demand](decisions/global/chats-get-every-demand.md): A role chat gets every demand a subagent would, 1:1, plus the cache; success is quality, speed and economy together
- [checks-once-each](decisions/global/checks-once-each.md): Every check runs once, by one role; full suites only at milestones; heavy runs take a machine lock
- [decisions-are-the-owners-technical-choices-are-mine](decisions/global/decisions-are-the-owners-technical-choices-are-mine.md): Goals, behaviour and rules are the owner's, recorded only when they decide; technical choices are mine, made and explained
- [designs-come-from-the-code-read](decisions/global/designs-come-from-the-code-read.md): A design for a system comes from reading its code; without that, bring measured facts and leave the design to its owning session
- [do-what-was-asked-then-the-root-cause](decisions/global/do-what-was-asked-then-the-root-cause.md): Do what was asked and nothing beside it; a negative result needs its cause, the strongest version and a root fix
- [extensions-no-path-closed](decisions/global/extensions-no-path-closed.md): Any plugin, skill, MCP server or tool must fit the agentic flow; a better one may replace a part, unchanged and pinned first
- [global-decisions-are-rules-not-quotes](decisions/global/global-decisions-are-rules-not-quotes.md): A global decision is stored as a rule, never as the owner's quote, so it ships with the template as written
- [keep-context-small](decisions/global/keep-context-small.md): Keep every session's context small: plugins off by default, filtered output, no schema-heavy skills for simple edits
- [layered-indexes-small-parts](decisions/global/layered-indexes-small-parts.md): Big files are split by topic into titled parts; indexes are layered by category, so no agent reads a whole file or a whole index
- [manager-owns-structure](decisions/global/manager-owns-structure.md): The managing session owns the structure; mechanical steps are scripts; the owner reads outputs and decides
- [manager-replies-in-the-users-language](decisions/global/manager-replies-in-the-users-language.md): The manager chat replies in the language the user writes in
- [measure-the-effect-of-every-improvement](decisions/global/measure-the-effect-of-every-improvement.md): Every improvement is measured by its real effect, not assumed to work
- [no-conversation-copies](decisions/global/no-conversation-copies.md): No copies of conversations anywhere; a hand-off keeps the main points; hand-off files reach subagents
- [no-one-agent-mode](decisions/global/no-one-agent-mode.md): No one-agent mode; a project's work runs as the multi-role pipeline
- [no-pointless-tests](decisions/global/no-pointless-tests.md): No tests that settle no decision; think from the evidence, fix everything known, launch once
- [owner-questions-and-status](decisions/global/owner-questions-and-status.md): Status in two or three lines; decisions asked once, in the coordinating chat, no popups
- [plan-whole-research-first-one-document](decisions/global/plan-whole-research-first-one-document.md): Plan the whole thing first, from researched sources, in one plan document
- [platform-native-manageable](decisions/global/platform-native-manageable.md): Builds on a platform use the platform's own tools and stay manageable by the owner without AI
- [plugins-load-per-session](decisions/global/plugins-load-per-session.md): What loads in a session is the manager's decision, never a global install
- [project-work-runs-through-the-pipeline-skill](decisions/global/project-work-runs-through-the-pipeline-skill.md): A project's work runs through the pipeline skill, never harness stages by default
- [reporting-cadence](decisions/global/reporting-cadence.md): Reporting cadence by kind of work - a batch is finished before the reply, a long run reports each minute, a search reports at the end
- [retry-loops-max-3](decisions/global/retry-loops-max-3.md): Every automatic retry or revise loop stops after 3 rounds; then decide by rule or escalate
- [sessions-close-by-the-watcher](decisions/global/sessions-close-by-the-watcher.md): Sessions close by the watcher, never by the owner
- [sessions-coordinate-between-themselves](decisions/global/sessions-coordinate-between-themselves.md): Sessions settle their contract between themselves; the owner gets finished results, never session names or a plan to re-approve
- [template-carries-what-user-relies-on](decisions/global/template-carries-what-user-relies-on.md): The template is every project's default structure; whatever the owner relies on is built into it
- [template-standing-requirements](decisions/global/template-standing-requirements.md): The template's standing requirements - any model and harness, a project brain with separate parts, a checkout that sets itself up
- [the-template-starts-any-complex-project-right](decisions/global/the-template-starts-any-complex-project-right.md): The default template exists to start any complex project right from the first day
- [truth-over-agreement](decisions/global/truth-over-agreement.md): Truth over agreement: correct the owner with evidence, give your own verdict
- [verify-every-template-change](decisions/global/verify-every-template-change.md): Every change to the template passes an independent verifier before it counts
- [verify-yourself-before-saying-done](decisions/global/verify-yourself-before-saying-done.md): Verify it yourself before saying it works - reproduce, operate every control, look at it, prove it fires on real data
- [writers-no-web-material-only](decisions/global/writers-no-web-material-only.md): Writers write only from our gathered, checked material; research is a separate verifiable stage
