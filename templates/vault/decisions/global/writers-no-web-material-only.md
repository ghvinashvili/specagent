# Writers: material only, no web

**Rule.** The writing role gets no internet tools. Articles are written only from material we gathered: the database, the fact sheet, checked quotes. Research (ingest, source reading, material building) is its own stage whose output is checkable, and gates check the text against the material afterwards.

**Why.** Accuracy and control: every number and date comes from the database and is checked by code, while a writer's own search risks invention and unchecked quotes.

**How to apply.**
- Give the writing role no internet tools, whichever model fills it.
- Widening the sources is the research stage's job, never the writer's.
- When the material is short (decided in code before the writer runs), the research stage finds more official sources itself: first a bounded number of links from the official pages already read to allowlisted official domains, then official catalogues that need no key. Code fetches every page, and the model gets text only, never a tool.
- A source that gave facts is proposed for the project's source list, which the main session reviews. The first case, one project's SEO pages (the owner's decision of 2026-10-25): `context/owner-statements/2026-10-25-seo-run-reporter.md`, item 4 (d).
